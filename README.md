A one-page newspaper front page for Thursday 19 November 2026: 46 stories
across 7 regions, with three illustrated leads, a BY THE NUMBERS strip, a
through-the-day UTC timeline, and a date check. Every story on the page
happened, or was first reported, on that day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` checks the image (PNG, 1024x1024, under 1 MiB) and copies it to
the output directory. The page itself is drawn by `render.py`, kept out of
this repository; `entry.png` here is the exact image the program outputs.
